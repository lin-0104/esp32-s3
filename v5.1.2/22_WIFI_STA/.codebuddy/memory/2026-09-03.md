## 22_WIFI_STA 工程调试

- 工程：ESP-IDF v5.1.2，WiFi STA 模式，含 components: WIFISTA / LCD / SPI / LED，main 调用 lcd_init + wifista_init。
- 用户遇到 CMake 配置失败（Configuring incomplete）+ ninja 找不到 build.ninja。
- 根因：IDE 用了 MinGW 的 cmake/ninja（C:\MinGW\mingw64\bin），而非 ESP-IDF 自带工具链。
- 正确工具链路径：
  - cmake: C:\Espressif\tools\cmake\3.24.0\bin\cmake.exe
  - ninja: C:\Espressif\tools\ninja\1.10.2\ninja.exe
  - idf.py.exe: C:\Espressif\tools\idf-exe\1.0.3\idf.py.exe
  - python: C:\Espressif\tools\idf-python\3.11.2\python.exe
  - IDF_PATH: C:\Espressif\frameworks\esp-idf-v5.1.2
  - IDE 为 espressif-ide (Eclipse 版)
- 代码修复（wifista.c）：
  1. 补 #include "esp_event.h"
  2. IP_EVENT_STA_GOT_IP 的 event_data 类型由 esp_netif_ip_info_t* 改为 ip_event_got_ip_t*，字段 event->ip 改为 event->ip_info.ip
- components/CMakeLists.txt 修复：component_compile_options(-ffast-math -O3 -Wno-error=format=-Wno-format) → (-ffast-math -O3 -Wno-format)
- 建议用户用 ESP-IDF Command Prompt 运行 idf.py build（绕开 IDE 工具链配置）。
